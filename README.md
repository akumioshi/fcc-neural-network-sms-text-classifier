# Neural Network SMS Text Classifier

## About the Project
A deep learning text classification model built using TensorFlow and Keras. It utilizes `TextVectorization` and an Embedding layer with a Dense neural network to classify SMS messages as either normal ("ham") or advertisement ("spam"). The model includes a custom `predict_message` function that successfully passes all automated unit tests.

## Technologies Used
- Python
- Pandas / NumPy
- TensorFlow / Keras (Sequential API, TextVectorization, Embedding)
- Google Colab
